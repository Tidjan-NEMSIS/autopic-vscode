## 2. Architecture Technique
- **Host IDE (`src/`) :**
  - Compilé avec `esbuild` (`node esbuild.config.js --production`) vers `dist/extension.js`.
  - Zéro dépendance runtime lourde (bundle autonome de ~68 Ko).
  - Vues :
    - `autopic.sidebarView` : Sidebar Webview View Provider dans l'Activity Bar (icône `assets/icons/autopic.svg`).
    - `autopic.openStudio` : Commande ouvrant le studio en plein écran (`StudioPanel.ts`).
  - Détection et Injection :
    - `PaletteDetector.ts` : détection dynamique de palettes dans les projets ouverts (Tailwind, CSS vars).
    - `CodeInjector.ts` : insertion au curseur adaptée au langage (React/Next.js JSX, HTML `<img>`, Markdown `![]`, Vue, Svelte).
- **Webview UI (`webview-ui/`) :**
  - Compilée avec `vite build` vers `dist/webview/`.
  - React 18, Vite 6, Tailwind CSS 3, Lucide React.
  - Fonctionnalités :
    - Double palette (Projet détecté vs Curseur de teinte libre HSL/HEX/Presets).
    - Recoloration vectorielle 0ms en mémoire (remplacement d'accents multi-fournisseurs).
    - Défilement infini sur 1800+ illustrations (Sentinel IntersectionObserver + Fallback button).
    - Grille responsive 1 à 6 colonnes et Modal Zoom HD panoramique (40% à 350%).
