## 2. Architecture Technique
- **Host IDE (`src/`) :**
  - Compilé avec `esbuild` (`node esbuild.config.js --production`) vers `dist/extension.js` (~79 Ko).
  - Vues :
    - `autopic.sidebarView` : Sidebar Webview View Provider dans l'Activity Bar (icône `assets/icons/autopic.svg`).
    - `autopic.openStudio` : Commande ouvrant le studio en plein écran (`StudioPanel.ts`).
  - Services clés :
    - `src/services/message-router.ts` : Routeur de messages unifié et bidirectionnel partagé entre Sidebar et Studio.
    - `src/services/autopic-bridge.ts` : Cache mémoire/disque avec TTL, timeouts robustes par provider, mapping `inspectProject`, scoring et `persist: false`.
    - `src/services/code-injector.ts` : Insertion intelligente multi-frameworks (React/Next.js JSX, HTML `<img>`, Markdown `![]`, Vue, Svelte, Flutter).
    - `src/services/PaletteDetector.ts` : Détection automatique des palettes de couleur projet (Tailwind, CSS vars).
- **Webview UI (`webview-ui/`) :**
  - Compilée avec `vite build` vers `dist/webview/`.
  - React 18, Vite 6, Tailwind CSS 3, Lucide React.
  - Fonctionnalités :
    - Store SVG en mémoire (`store/svgStore.ts`) : mise en cache du SVG brut et recoloration instantanée 0ms (`useMemo`).
    - Lazy loading des vignettes.
    - Zéro mock : alimentation directe depuis les flux réels.
    - Défilement infini optimisé avec conteneur unique `h-screen overflow-hidden` et `min-h-0 overflow-y-auto`.
    - Double palette (Projet détecté vs Curseur de teinte libre HSL/HEX/Presets).
    - Lightbox Modal Zoom HD panoramique (40% à 350%).
